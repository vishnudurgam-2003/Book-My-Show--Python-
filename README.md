### 🎬 BookMyShow Clone Project

A *Python-based BookMyShow Clone Application* that allows users to browse movies, book tickets, and manage bookings, while admins can manage movie listings and view booking details.  
This project uses *MySQL* for database management and follows an *object-oriented structure* with separate modules for Admin, User, and Booking functionalities.

### 📁 Project Structure

---

## ⚙ Features

### 👨‍💼 Admin Module
- Add new movies with details (name, genre, show time, ticket price)
- Update or remove existing movies
- View all bookings and customer details

### 👤 User Module
- Register and login
- Browse available movies
- Select show time and seats
- Book tickets and view booking history

### 💾 Database (MySQL)
- Movies table  
- Users table  
- Bookings table  

All modules are connected using a centralized database connection file.
